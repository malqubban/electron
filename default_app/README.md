# معاينة واجهة "الميدان الرياضي"

يوضّح هذا الدليل كيفية تشغيل نسخة الواجهة الخاصة بـ «دار اليوم القابضة» داخل مجلد `default_app` من دون الحاجة إلى بناء تطبيق Electron كامل.

## المتطلبات المسبقة
- Python 3.8 أو أحدث (موجود افتراضياً في معظم البيئات التطويرية)

## خطوات التشغيل
1. افتح الطرفية داخل مجلد `default_app`:
   ```bash
   cd default_app
   ```
2. شغّل خادماً محلياً بسيطاً:
   ```bash
   python3 -m http.server 8000
   ```
3. افتح المتصفح على العنوان `http://localhost:8000/index.html` لمعاينة الصفحة.

> **ملاحظة:** يحمّل هذا الخادم ملفات HTML وCSS وSVG مباشرةً، لذا ستحصل على الشكل النهائي نفسه الظاهر داخل تطبيق Electron.

## إيقاف الخادم
اضغط `Ctrl + C` في نفس النافذة لإيقاف الخادم عند الانتهاء من المعاينة.
